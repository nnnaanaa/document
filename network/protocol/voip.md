# VOIP.md
## VoIP（SIP / SDP / RTP / 音声のデジタル化）

***

## VoIP の概要

**VoIP** (Voice Over Internet Protocol)
* **電話などの音声データをIPネットワーク経由で配送**するためのプロトコル
* 電話は基本的に電話線を介してやり取りされるが、それをIPネットワークを介して行う
* IPネットワークと設備が共通化することで様々なメリットが得られる
  * 例: 電話線に比べ大幅なコスト削減, 電話線に比べ拡張が容易, インターネットさえあれば利用可能 …

| 構成要素 | 役割 |
| --- | --- |
| **PBX** (Private Branch eXchange) | 内線や外線の接続等を担う（従来の電話システム: 固定電話 ─ PBX ─ 公衆電話網） |
| **VoIPゲートウェイ** | 電話線のアナログデータをデジタルに変換 |
| **IP-PBX** | IP網においてPBXと同じ役割を持つ |

VoIPシステムの例: 固定電話 ─ PBX ─ VoIPゲートウェイ ─ IP-PBX ─ インターネット（IP電話もIP-PBXに接続）

## VoIP 通話の流れ

### 1. SIP (Session Initiation Protocol) による呼制御（シグナリング）

* **SIP**: **電話機間の接続（電話番号からIPアドレスを特定, 相手の電話機を呼び出し, 通話の切断 … 等）**を実現
* SIPの機能を末端の電話機すべてが持つのは非効率なため、一般的に **SIPサーバー**を経由する
  * SIPサーバーは**通話の制御のみ**を担当し、音声データ自体は**直接通信**される場合が多い
* SIPでは **SDP** (Session Description Protocol) と呼ばれる形式に則り電話機間の接続に必要な情報を交換
  * **SDP**: SIPにおいて音声or動画, セッション名, 使用するポート番号 等の情報を含む。メディア形式の詳細を提供し、双方でのメディア設定を統一する

※ IP-PBX が SIP サーバーの役割を持つ場合や、SIP サーバーが別途独立して存在する場合もある。

### 2. RTP (Real-time Transport Protocol) による音声通話

* **RTP**: エンドユーザー間で音声や動画などの**リアルタイム性が必要なデータの転送を実現**
* リアルタイム性確保のために **UDP上で動作するが、RTPがリアルタイム性を確保するため、ジッターやパケットロスを最小化する設計がされている**
* 通信品質などの付加情報は **RTCP** (Real-time Transport Control Protocol) が担う
  * **RTCP**: パケットロス, ジッター, ラウンドトリップタイム … 等の付加情報をやり取りする。**受信側からのフィードバックを送信側に提供**し、品質の改善を図るためのプロトコル

**ジッター** (Jitter): ネットワークを通じてデータが送受信される際のパケット到着時間のばらつき。

### シーケンス（IP電話 ─ SIPサーバー ─ IP電話）

| 順 | メッセージ | 方向 | 意味 |
| --- | --- | --- | --- |
| 1 | **REGISTER** | 各IP電話 → SIPサーバー | 自身の情報（IPアドレス等）を登録 |
| 2 | **INVITE** | 発信側 → SIPサーバー → 着信側 | 接続開始のリクエスト |
| 3 | **200 OK** | 着信側 → SIPサーバー → 発信側 | 正常に受け付けた旨を応答 |
| 4 | **ACK** | 発信側 → 着信側 | 接続の確立を通知 |
| - | （RTPによる音声通話） | 発信側 ⇔ 着信側 | - |
| 5 | **BYE** | 発信側 → 着信側 | 接続の終了を通知 |
| 6 | **200 OK** | 着信側 → 発信側 | 正常に受け付けた旨を応答 |

## 音声をデジタルデータに変換

| 工程 | 内容 |
| --- | --- |
| 音声の**標本化** | アナログ信号を一定間隔でサンプリングする。**標本化定理**に従い、**アナログ信号の周期の2倍以上でサンプリング**する必要がある（例: アナログ信号が4kHzの場合、8kHzでサンプリングすることでアナログ信号を忠実に再現できる） |
| 音声の**量子化** | サンプリングした値を離散的な数値に変換する工程。標本化した**信号にそれぞれ数値を割り当てる** |
| 音声の**符号化** | 量子化によって割り当てた**数値を2進数のデータに変換する**。現在ではそのまま2進数に変換せず、**圧縮**することが多い |

* 標本化: 連続的に変化するアナログ信号（例えば音声）を、**一定の間隔で「測定（標本化）」すること**。例えばCD音質の音声は1秒間に44,100回（44.1kHz）
* 量子化: アナログ信号の**連続的な変化を一定の間隔で区切り**、それぞれに具体的な数値を割り当てること
* 符号化はデータの変換工程であり、圧縮はデータサイズを縮小するための別の技術

| 符号化方式 | 詳細 |
| --- | --- |
| **PCM** (Pulse Code Modulation) | 量子化されたデータをそのまま符号化, VoIPでは **64 kbps** 程度の帯域幅を消費 |
| **CS-ACELP** (Conjugate-Structure Algebraic Code Excited Linear Prediction) | 量子化されたデータをあらかじめ用意しておいたパターンに置き換えて符号化, VoIPでは **8kbps** 程度の帯域幅を消費（PCMに比べて音質が劣る） |
