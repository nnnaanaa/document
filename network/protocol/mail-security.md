# MAIL-SECURITY.md
## 送信ドメイン認証（SPF / DKIM / DMARC）

***

## SPF (Sender Policy Framework) レコード

ドメイン所有者がメールを送信する際に使用するメールサーバを指定するためのDNSレコード。**TXTレコード**に記述する。

受信側のメールサーバは送信元のメールサーバがそのドメインから送信することを許可されているかどうかを検証できる。スパムやフィッシング攻撃を防ぐための重要な手段。

```
v=spf1 include:_spf.example.com -all
```
→ `_spf.example.com` ドメインに指定されたSPFレコードを参照し、そのドメインが許可する送信元からのメールを許可する。

```
v=spf1 ip4:192.0.2.1 ip4:198.51.100.2 -all
```
→ 192.0.2.1 と 198.51.100.2 の両方のIPアドレスからの送信を許可する。

| 修飾子 | 意味 |
| --- | --- |
| **-all** | すべての送信元以外のメールは**認証失敗**として扱う。ドメインのメールサーバー以外から送信されたメールはSPF認証に失敗し、通常は拒否される |
| **~all** | すべての送信元以外のメールは**ソフトフェイル**として扱う。SPF認証に失敗しても必ずしも拒否されるわけではなく、受信側のサーバーがそのメールをソフトフェイルとしてマーク（警告を出すなど）することがある |

## DKIM (DomainKeys Identified Mail) レコード

送信者が電子メールの送信元ドメインの所有者であることを確認できる。送信者はメッセージに**デジタル署名**を付けて送信し、受信者はその署名を検証してメッセージの送信元を確認できる。

DKIMレコードには、ドメインの**公開鍵**が含まれており、これを使用して電子メールの送信者が署名したメッセージを検証できる。受信側のメールサーバーは、DKIMレコードから公開鍵を取得し、送信者が署名したメッセージを解読して送信元のドメインを確認する。**TXTレコード**に記述する。

```
selector1._domainkey.example.com TXT "v=DKIM1; k=rsa; p=MIGfMA0GCSqGSIb3DQEBAQUAA4GNADCBiQKBgQDc3lzLWjvm4bj4g8EKsHu7PvWj..."
```

| 項目 | 意味 |
| --- | --- |
| `v=DKIM1` | DKIMのバージョンを示す |
| `k=rsa` | RSAアルゴリズムを使用して暗号化されたキーを使用していることを示す |
| `p=...` | 公開鍵がBase64でエンコードされている |

## DMARC (Domain-based Message Authentication, Reporting, and Conformance) レコード

DMARCは、**DKIMとSPFを組み合わせて使用**し、メールの送信ドメインの認証と信頼性を強化する。送信ドメインがDKIMやSPFを使用してメール送信を保護していることを示し、受信ドメインのメールサーバーにポリシーを提供する。DMARCのポリシーは、**DKIMとSPFの結果に基づいて、メールの受信後の処理方法を指定**する。

```
_dmarc.example.com. IN TXT "v=DMARC1; p=none; rua=mailto:dmarc@example.com; ruf=mailto:dmarc@example.com; fo=1"
```

| 項目 | 意味 |
| --- | --- |
| `v=DMARC1` | DMARCのバージョンを示す |
| `p=none` | DMARCポリシーを定義する。"none"は受信したメールに対してDMARCが適用されないことを示す。他に `quarantine`（迷惑メールフォルダに移動）や `reject`（メールを拒否）がある |
| `rua=mailto:...` | ポリシー適用の**アグリゲートレポート**を送信するためのメールアドレスを示す |
| `ruf=mailto:...` | ポリシー適用の**フォレンジックレポート**を送信するためのメールアドレスを示す |
| `fo=1` | DMARCフォルワーディングオプション。「1」は、DMARC違反レポートを送信するときに、元のメールの一部を含めるよう指示している |

アグリゲートレポート（Aggregate Report）とフォレンジックレポート（Forensic Report）は、いずれもドメイン所有者に対してメールの認証状況や不正なメールの検出情報を提供するレポート。
