# UDP.md
## UDPヘッダー構造/フィールド

出典: [RFC 768 - User Datagram Protocol](https://www.ietf.org/rfc/rfc768.html)

***

## ヘッダー構造

```
 0      7 8     15 16    23 24    31
+--------+--------+--------+--------+
|     Source      |   Destination   |
|      Port       |      Port       |
+--------+--------+--------+--------+
|                 |                 |
|     Length      |    Checksum     |
+--------+--------+--------+--------+
```

**合計8Byteの固定ヘッダー**（TCPのように可変長オプションを持たない）。

| フィールド | 意味 |
| --- | --- |
| Source Port (送信元ポート) | 送信元のポート番号 |
| Destination Port (宛先ポート) | 宛先のポート番号 |
| Length (レングス) | UDPヘッダ＋データのサイズを示す |
| Checksum (チェックサム) | エラーチェック用の値 |

TCPと異なり、シーケンス番号・確認応答番号・ウィンドウ制御など、コネクション管理や順序保証の仕組みを持たない。
