# IEEE802X.md
## ネットワークスペシャリスト試験に頻出するIEEE 802.X規格

出典: [ネットワークスペシャリスト試験に頻出するIEEE802.Xを一覧化してみた](https://qiita.com/y-vectorfield/items/1931b5c3c7f680a81a06)

***

## 1. PoE（給電）関連規格

イーサネット配線で利用されるツイストペアケーブルを介して、データと電力を同時に供給する技術。

| 規格 | 通称 | 最大給電電力 |
| --- | --- | --- |
| **IEEE 802.3af** | PoE | 15.40W |
| **IEEE 802.3at** | PoE+ | 30.0W |
| **IEEE 802.3bt** | PoE++ | 60W / 99W |

***

## 2. 無線LAN（Wi-Fi）関連規格

| 規格 | 周波数帯 | 最大伝送速度 |
| --- | --- | --- |
| **IEEE 802.11a** | 5GHz帯 | 54Mbps |
| **IEEE 802.11b** | 2.4GHz帯 | 11Mbps |
| **IEEE 802.11g** | 2.4GHz帯 | 54Mbps |
| **IEEE 802.11n** | 2.4GHz帯 / 5GHz帯 | 600Mbps |
| **IEEE 802.11ac** | 5GHz帯 | 6.9Gbps |
| **IEEE 802.11ax** | 2.4GHz帯 / 5GHz帯 | 9.6Gbps |
| **IEEE 802.11be** | 2.4GHz帯 / 5GHz帯 / 6GHz帯 | 46Gbps |

Wi-Fiの世代名称（Wi-Fi4/5/6）・変調方式・暗号化方式・ローミングなどの詳細は[wifi.md](wifi.md)を参照。

***

## 3. セキュリティ関連規格

### IEEE 802.11i
暗号化アルゴリズムに**AES**を初めて採用した**WPA2**が準拠する方式。

### IEEE 802.1X認証
イーサネットや無線LANで使用される認証プロトコル。以下の3要素で構成される。

| 要素 | 役割 |
| --- | --- |
| **サプリカント** | 認証を受ける側の端末（クライアント） |
| **オーセンティケータ** | 認証を中継する機器（スイッチ・アクセスポイント等） |
| **認証サーバ** | 実際に認証を行うサーバ（RADIUSサーバ等） |

***

## 4. その他ネットワーク機能規格

### IEEE 802.1Q
VLANタグの標準フォーマットを策定した規格。

***

## まとめ

* PoE系（802.3af/at/bt）は**給電能力の違い**（15.4W → 30W → 60/99W）を覚える
* 無線LAN系（802.11a/b/g/n/ac/ax/be）は**世代ごとの周波数帯と最大速度**を覚える
* セキュリティ系（802.11i、802.1X）は**WPA2＝AES**、**802.1X＝サプリカント/オーセンティケータ/認証サーバ**の構成を覚える
* 802.1QはVLANタグのフォーマット規格
