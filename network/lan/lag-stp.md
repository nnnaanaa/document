# LAG-STP.md
## LAG (Link Aggregation) と STP / BPDU

***

## LAG (Link Aggregation)

L2（データリンク層）の技術。**複数のリンクを束ねて1つの論理的なリンクとして利用する**技術。L2/L3ポートの両方で利用可能で、スイッチ間やスイッチとサーバー間でよく使用される。**Static**に設定する場合と、**LACP**（Link Aggregation Control Protocol）を使用する場合がある。

**メリット**: 帯域拡大, 冗長化, STPと違いブロッキングポートが生じず構成が分かりやすい

| 構成 | 内容 |
| --- | --- |
| **LAGによるL2ネットワーク** | 2つのリンクを**論理的に1つのリンク**として扱う（リンクとは通信経路をさす） |
| **STPによるL2ネットワーク** | ループ防止のために**ブロッキングポート**が生じる |

## BPDU (Bridge Protocol Data Unit)

STPネットワークの構築やループの検出を動的に行うための**制御用フレーム**。

**役割**: ルートブリッジの選定、ループの検出と回避、トポロジーの変更検知、スイッチポートのステート管理

BPDUがあるおかげで、リンク障害等により既存の通信経路が利用不可となった場合、**動的に新たな通信経路**を構築する。各スイッチは、自分の情報をBPDUとして定期的に送信する。**マルチキャストMACアドレス (01:80:C2:00:00:00)** で送信される。

**BPDUのフィールド（一部抜粋）:**

| フィールド | 詳細 |
| --- | --- |
| Root ID（ルートID） | ルートブリッジのブリッジID |
| **Path Cost**（パスコスト） | ルートブリッジまでの距離を示し、帯域幅から計算される。**10Gbps=2 \| 1Gbps=4 \| 100Mbps=19 \| 10Mbps=100** |
| **Bridge ID**（ブリッジID） | **プライオリティ＋MACアドレス**で構成されるSTPスイッチの識別子。ルートブリッジの選出する際に利用される |
| Port ID（ポートID） | **プライオリティ＋ポート番号**で構成されるポートの識別子。ポートの役割を選出する際に利用される |

## ルートブリッジ

STPネットワークの中心となるスイッチ。**全スイッチの基準**となるスイッチで、**ネットワーク内の全通信パスのルート**。各スイッチはルートブリッジに至る最短パス（経路）を選択することでループを回避する。

* BPDU内の**ブリッジID**（プライオリティ＋MACアドレス）フィールドが**最も小さい**スイッチが選出される
* プライオリティを設定した場合: 意図的に特定のスイッチをルートブリッジとして選出できる
* プライオリティを設定しない場合: **MACアドレスの小さいスイッチ**がルートブリッジとして選出される

例）4台のスイッチがそれぞれプライオリティ 20 / 0 / 10 / (中央上) を名乗る場合、**プライオリティが最小（0）のスイッチ**がルートブリッジとして選出される。
