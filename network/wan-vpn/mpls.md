# MPLS.md
## IP-VPN / MPLS

***

## IP-VPN

* **プロバイダが提供する閉域IP網経由で拠点間を接続すること**を指す
* IP-VPNを実現するために、プロバイダ内では **MPLS** が利用されることが多い
* L3トンネリング技術

## MPLS (Multi Protocol Label Switching)

* パケットにラベルを付与し、**ラベルの情報を基にパケットを転送**するプロトコル
* **ラベルは 4 Byte と軽量なため、IPヘッダ (20 Byte) を参照するルーティングに比べて高速に動作**する
* また、**ラベルで利用者を識別できる**ため、プロバイダは複数の利用者を一つのIP網に収容できる

```
CE ─IPパケット→ LER/PE ─[ラベル10|IPパケット]→ LSR ─[ラベル20|IPパケット]→ LER/PE ─IPパケット→ CE
                 (Insert)                     (Swap)                      (Untag)
                 └──────────────── LSP ────────────────┘
```

## MPLS 用語

| 分類 | 用語 | 詳細 |
| --- | --- | --- |
| ルーターの名称 | **CE** (Customer Edge) | 顧客側のIP網への出口となるルーター |
| ルーターの名称 | **PE** (Provider Edge) | プロバイダ側のIP網の入り口となるルーター |
| ルーターの名称 | **LER** (Label Edge Router) | プロバイダ管理のルーター / ラベルの Insert, Untag を担う |
| ルーターの名称 | **LSR** (Label Switching Router) | プロバイダ管理のルーター / ラベルの Insert, Swap, Remove を担う |
| 概念 | **LSP** (Label Switching Path) | ラベルが付与されたパケットが辿る経路 |
| 概念 | **FEC** (Forwarding Equivalence Class) | MPLSにおいて同じ転送処理を行うパケットのグループを示す。QoSや宛先IPアドレス等で分類することで効率的な転送が可能になる |
| ラベル操作の名称 | Insert | ラベルを付与すること（2つ以上のラベルが付与された状態を**スタック**と呼ぶ） |
| ラベル操作の名称 | Swap | ラベルを付け替えること |
| ラベル操作の名称 | Remove | ラベルを1つ除去すること |
| ラベル操作の名称 | Untag | ラベルをすべて除去すること |

ネットワークスペシャリスト試験では、ラベルによって転送されるイメージと用語を押さえておけば概ね回答可能なはず。
