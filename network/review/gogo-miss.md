## ルーティング

| 番号 | 問われたこと | 答え | 覚え方 |
| --- | --- | --- | --- |
| 9 | OSPF で LSDB から作る木（令和6年 午後II 問1） | **最短経路ツリー（SPF ツリー）** | ダイクストラ法で、コストの合計が最小になる経路の木を作る。 |
| 12 | BGP で経路の追加・削除を伝えるメッセージ（令和5年 午後II 問1） | **UPDATE** | パスアトリビュート（LOCAL_PREF・AS_PATH・MED など）は UPDATE に載る。 |
| 13 | BGP の4種類のメッセージ（タイプ1〜4）（令和5年 午後II 問1） | **OPEN／UPDATE／NOTIFICATION／KEEPALIVE** | 開始（OPEN）→ 経路（UPDATE）→ エラー（NOTIFICATION）→ 生存確認（KEEPALIVE）。HELLO は OSPF。 |
| 17 | OSPF の Type 1 の LSA の名前と、含まれるメトリック（令和3年 午後I 問2） | **ルータ LSA／コスト** | Type 1 ルータ、Type 2 ネットワーク、Type 3 サマリー、Type 5 AS 外部。OSPF のメトリックはコスト（ホップ数は RIP）。 |
| 19 | 172.16.0.0/23〜172.16.12.64/26 を /16 に集約（令和3年 午後I 問2） | **172.16.0.0** | /16 なので第1・第2オクテットだけを残し、残りは 0。長さの指定がなく最小に集約するなら 172.16.0.0/20。 |
| 20（1） | BGP の最適経路の選択で、LOCAL_PREF の次に比べるもの（令和3年 午後II 問2） | **AS_PATH の長さ（短いほうを優先）** | LOCAL_PREF 大 → AS_PATH 短 → ORIGIN（IGP → EGP → Incomplete）→ MED 小 → eBGP 優先 → NEXT_HOP が近い → ルータ ID 小 → ピアの IP 小。 |
| 20（2） | BGP の最適経路の選択で、値が大きいほうを優先するもの（令和3年 午後II 問2） | **LOCAL_PREF** | LOCAL_PREF だけが「大きいほうが優先」。あとは小さい・短い・近いほうが優先。 |

## 無線 LAN

| 番号 | 問われたこと | 答え | 覚え方 |
| --- | --- | --- | --- |
| 145（1） | SSID が空白か any の接続要求を拒否する機能（平成29年 午後II 問2） | **ANY 接続拒否** | ビーコンに SSID を含めないのは SSID 隠蔽。どちらも単独では対策にならない。 |
| 145（2） | ビーコンに SSID を含めない機能（平成29年 午後II 問2） | **SSID 隠蔽（ステルス）** | アクセス制御の方式は SSID、ANY 接続拒否、SSID 隠蔽、MAC アドレスフィルタリング、IEEE 802.1X 認証。 |
| 146 | WPA2 が準拠する規格（平成29年 午後II 問2） | **IEEE 802.11i** | 802.1X は認証、802.11w は PMF、802.11r は高速ローミング。 |
| 148 | WEP が解読されやすい理由（平成29年 午後II 問2） | **同一の WEP キーを使い続けるため** | WEP は RC4（共通鍵・ストリーム暗号）、WPA は RC4 ＋ TKIP、WPA2 は AES ＋ CCMP（802.11i）。 |
| 150 | WPA2 でハンドオーバを短くするしくみ（平成29年 午後II 問2） | **事前認証と PMK の保持（PMK キャッシュ）** | 移る前に認証を済ませる、戻ってきた AP では PMK を作り直さない。 |
| 151 | 867Mbps を出すのに必要な帯域幅とアンテナ本数（製品は 80MHz まで）（平成29年 午後II 問2） | **80MHz／2本** | 80MHz なら1本あたり約 433Mbps（半分）→ 2本で約 867Mbps。速度は帯域幅とアンテナ本数に比例。 |
| 152 | 同じパスフレーズを両方に設定する認証（平成28年 午後I 問2） | **事前共有鍵（PSK）認証** | WPA2 パーソナルの方式。 |
