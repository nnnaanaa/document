# VXLAN.md
## VXLAN 直前シート

元のシート: [VXLAN 暗記シート](../lan/vxlan.md)

### 要点

| 論点 | 覚えること |
| --- | --- |
| VNI | **24bit・約1,677万**（VLAN は 12bit・4,094） |
| UDP ポート | **4789**。**送信元ポートはハッシュ値** → ECMP で負荷分散 |
| MTU | **50Byte 増える** → アンダーレイの MTU 不足で大きいパケットだけ通らない |
| VTEP の IP | **ループバック**に付ける |
| Leaf-Spine | **ECMP** で STP 不要。Spine は VTEP ではない |
| ルートリフレクタ | iBGP のフルメッシュを避けるため **Spine を RR** に |
| エニーキャスト GW | **VM が移動してもゲートウェイが変わらない** |
| マルチテナント | VNI を分ければ **IP アドレスが重複してもよい** |
| Flood & Learn と EVPN | Flood & Learn は**マルチキャスト（PIM）**が必要。**EVPN は MP-BGP** |
| EVPN の経路 | **Type 2（MAC/IP）**、**Type 3（BUM の送り先）**、**ARP 抑制** |
| ESI | 2台の Leaf への LAG の**共通の識別子**。BUM は **DF だけ**が送る |

### 答えの型

| 問われ方 | 答えの型 |
| --- | --- |
| VLAN ではなく VXLAN の理由 | 「VNI が **24bit** で多く作れ、**L3 をまたいで L2 を延長**できる」 |
| 大きいパケットだけ通らない原因と対策 | 「**50 バイト**増え**アンダーレイの MTU を超える**」→「**MTU を大きくする**」 |
| 送信元ポートをハッシュ値にする理由 | 「フローごとに変わり、**ECMP で負荷分散**されるから」 |
| VTEP をループバックにする理由 | 「**物理 IF が故障しても**ほかの経路で到達できるから」 |
| EVPN でフラッディングが減る理由 | 「**MP-BGP** で MAC と VTEP の対応を**事前に学習**するから」 |
| ARP 抑制の効果 | 「VTEP が**代わりに ARP に応答**し、ブロードキャストを流さずに済む」 |
