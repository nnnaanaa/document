# TCP-QOS.md
## TCP・QoS 直前シート

元のシート: [TCP・QoS 暗記シート](../protocol/tcp-qos.md)

### 要点

| 論点 | 覚えること |
| --- | --- |
| MSS | **MTU − 40**（1,500 なら 1,460）。トンネルでは MSS を小さく |
| PPPoE の MTU | **1,492Byte** |
| 高速再送 | **重複 ACK 3回** |
| フロー制御 / 輻輳制御 | **フロー制御は受信側の都合**、**輻輳制御はネットワークの都合** |
| スループット | 上限 ≒ **ウィンドウサイズ ÷ RTT**。遅延が大きいと下がる |
| 無通信の切断 | FW の**無通信タイムアウト** → **キープアライブ** |
| マーキング | **CoS は VLAN タグの 3bit**、**DSCP は IP ヘッダの 6bit**（音声は **EF**） |
| シェーピング / ポリシング | **シェーピングはためて遅らせる**、**ポリシングは捨てる** |
| PQ | 高い優先度が続くと**低い優先度が送られない** |
| 音声 | **UDP（RTP）**。**最優先** |

### 答えの型

| 問われ方 | 答えの型 |
| --- | --- |
| 遅延が大きいと遅い理由 | 「**ACK を待つ時間が長く**なり、送れる量が減るから」 |
| ロスが多いと遅い理由 | 「ロスを**輻輳と判断して送信量を絞る**から」 |
| 音声に UDP の理由 | 「**再送による遅延**が品質を下げるから」 |
| 無通信で切断される理由 | 「FW が**通信のないセッション情報を削除**するから」 |
| 入口で値を付け直す理由 | 「端末が**勝手に高い優先度**を付けた通信を優先させないため」 |
| CoS ではなく DSCP の理由 | 「**CoS は VLAN タグの中**で、ルータを越えると失われるから」 |
| シェーピングの理由 | 「**契約帯域を超えた分が網で捨てられる**のを防ぐため」 |
