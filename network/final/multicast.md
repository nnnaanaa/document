# MULTICAST.md
## マルチキャスト 直前シート

元のシート: [マルチキャスト 暗記シート](../routing/multicast.md)

### 要点

| 論点 | 覚えること |
| --- | --- |
| 届き方 | **送信1回で参加した端末だけ**に届く。**UDP** |
| IP アドレス | **224.0.0.0/24 はルータを越えない**。組織内は **239.0.0.0/8** |
| MAC アドレス | **01-00-5E ＋ IP の下位23bit** → **32個の IP が同じ MAC** |
| IGMP と PIM | **IGMP は端末とルータ**、**PIM はルータ同士** |
| IGMP の版 | **v2 は Leave Group**、**v3 はソースフィルタ**（PIM-SSM に必要） |
| IGMP スヌーピング | L2SW が**受信端末のいるポートにだけ**流す |
| PIM-DM / PIM-SM | **DM は Flood & Prune**、**SM は RP と join** |
| PIM-SSM | 受信側が**送信元 S を指定**（IGMPv3）→ RP 不要 |
| RPF チェック | **ループを防ぐ** |

### 答えの型

| 問われ方 | 答えの型 |
| --- | --- |
| マルチキャストの利点 | 「受信端末が増えても、**配信サーバと回線の負荷が増えない**」 |
| IGMP スヌーピングの理由 | 「受信端末のいないポートへの**不要な転送を止める**ため」 |
| IGMPv2 の改善点 | 「**Leave Group** で、**不要な配信を早く止められる**」 |
| PIM-SM が WAN に向く理由 | 「**join を送ったルータにだけ**配信するから」 |
| PIM-DM が WAN に向かない理由 | 「最初に**全ルータへ流す**から」 |
| RPF チェックの目的 | 「送信元への経路と違う IF から来たものを捨て、**ループを防ぐ**」 |
| 受信端末が IP も確認する理由 | 「**複数の IP が同じ MAC** に対応するから」 |
