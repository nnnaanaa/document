# IPV6.md
## IPv6 直前シート

元のシート: [IPv6 暗記シート](../ip-address/ipv6.md)

### 要点

| 論点 | 覚えること |
| --- | --- |
| アドレスの種類 | **リンクローカル `fe80::/10`**、**ULA `fc00::/7`**、**マルチキャスト `ff00::/8`**、**GUA `2000::/3`** |
| 省略 | `::` は**1回だけ** |
| Modified EUI-64 | `fffe` を挟む ＋ **U/L ビット反転（先頭バイト +2）** |
| ヘッダ | **40Byte 固定**、**チェックサムなし**、TTL → **Hop Limit** |
| フラグメント | **ルータは分割しない** → **Packet Too Big（ICMPv6 タイプ2）**で PMTUD。最小 MTU **1280** |
| ARP の代わり | **NDP（NS / NA）**。要請ノードマルチキャスト宛て |
| DAD | 送信元 `::` の NS。**NA が返れば重複** |
| RA の M / O フラグ | DHCPv6 の使い方を指示。**DHCPv6 ではデフォルトゲートウェイを配れない**（RA が必要） |
| ICMPv6 | **NDP・PMTUD に必要**なので全部は止めない |
| 移行技術 | **NAT64/DNS64**（`64:ff9b::/96`）、**DS-Lite / MAP-E**（IPv4 over IPv6） |
| IPv6 版 | **OSPFv3 はリンクローカルで隣接**、DHCPv6 は UDP **546/547** |

### 答えの型

| 問われ方 | 答えの型 |
| --- | --- |
| ICMPv6 を全部遮断してはいけない理由 | 「**NDP や PMTUD** に使われ、遮断すると **IPv6 の通信ができなくなる**から」 |
| 大きいデータだけ届かない原因 | 「FW が **Packet Too Big を遮断**し、送信元が**経路 MTU を知ることができない**から」 |
| FW をより慎重に設計する理由 | 「**NAPT を使わず**、端末に**グローバルアドレス**が付き、外から**直接到達できる**から」 |
| DHCPv6 でも RA が必要な理由 | 「DHCPv6 では**デフォルトゲートウェイを通知できない**から」 |
| 一時アドレスを使う理由 | 「**MAC アドレスから作った** ID では、**端末を追跡される**から」 |
| RA Guard の目的 | 「**不正な RA** で**デフォルトゲートウェイを乗っ取られる**のを防ぐ」 |
