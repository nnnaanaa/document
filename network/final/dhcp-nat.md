# DHCP-NAT.md
## DHCP・NAT 直前シート

元のシート: [DHCP・NAT 暗記シート](../protocol/dhcp-nat.md)

### 要点

| 論点 | 覚えること |
| --- | --- |
| 順序 | **DISCOVER → OFFER → REQUEST → ACK**。UDP **67**（サーバ）・**68**（クライアント） |
| ブロードキャスト | **DISCOVER と REQUEST** |
| リレーエージェント | セグメントが違うとき。サーバは **giaddr** で配布範囲を決める |
| リースの更新 | **50% でユニキャスト**、**87.5% でブロードキャスト** |
| DHCP スヌーピング | **不正な DHCP サーバ**を防ぐ。その表で **ARP スプーフィング**・**IP ソースガード**も |
| 169.254.x.x | DHCP で**取れなかった**印 |
| NAPT | **ポート番号で端末を区別**。**外部からは始められない** |
| ポートの枯渇 | SaaS で**セッションが増える**と起きる → グローバル IP を増やす |

### 答えの型

| 問われ方 | 答えの型 |
| --- | --- |
| リレーエージェントが必要な理由 | 「DHCP の**ブロードキャストはルータを越えない**から」 |
| 配布範囲の決め方 | 「リレーが書いた **giaddr** からサブネットを判断する」 |
| REQUEST をブロードキャストする理由 | 「**選ばなかった DHCP サーバにも**知らせるため」 |
| リース期間を短くする理由 | 「早く回収し、**アドレスの枯渇を防ぐ**ため」 |
| DHCP スヌーピングの目的 | 「**不正な DHCP サーバ**の偽の設定を受け取らないようにする」 |
| NAPT の内側へ接続できない理由 | 「**変換テーブルに対応する行がない**から」 |
| セッションが張れない理由 | 「1つのグローバル IP の**ポート番号を使い切った**から」 |
