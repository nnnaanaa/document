# L2-REDUNDANCY.md
## L2 冗長化 直前シート

元のシート: [L2 冗長化 暗記シート](../lan/l2-redundancy.md)

### 要点

| 論点 | 覚えること |
| --- | --- |
| ループ | **ブロードキャストストーム** → VLAN 全体が通信できない |
| ルートブリッジ | **ブリッジ ID が最小**。優先度を小さくしてコアスイッチに決めておく |
| ポートの役割 | **ルートポートは各スイッチに1つ**、**指定ポートは各リンクに1つ**、残りがブロッキング |
| 切替え時間 | STP **最大 50秒**、**RSTP 数秒以内** |
| エッジポート | **PC 用ポート**。すぐ転送を始める。**BPDU ガード**と組み合わせる |
| MSTP | VLAN のグループごとにツリー → **負荷分散** |
| リンクアグリゲーション | **フロー単位**で振り分け。**1つの通信は1本分の速度** |
| LACP | 対向の**設定誤りやリンク異常を検知**して外せる |
| スタック ＋ LAG | **STP に頼らず全リンクを使える** |

### 答えの型

| 問われ方 | 答えの型 |
| --- | --- |
| ループで VLAN 全体が止まる理由 | 「ブロードキャストが**回り続けて増え**、帯域と処理能力を使い切るから」 |
| ルートブリッジを明示的に決める理由 | 「意図しないスイッチがなり、**経路が遠回り**になるのを防ぐため」 |
| エッジポートにする理由 | 「**すぐ転送を始め**、PC 起動時の DHCP などの失敗を防ぐため」 |
| BPDU ガードの理由 | 「**スイッチを勝手につなぐ**ことによるループや再計算を防ぐため」 |
| 2本束ねても1通信が速くならない理由 | 「フロー単位なので、**1つの通信は1本しか使わない**から」 |
| STP で帯域がむだになる理由 | 「ブロッキングのリンクは**ふだん使われない**から」 |
