# OSPF.md
## OSPF 直前シート

元のシート: [OSPF 暗記シート](../routing/ospf.md)

### 要点

| 論点 | 覚えること |
| --- | --- |
| 方式 | **リンクステート型**、**ダイクストラ法**、**コストの合計が最小** |
| コスト | **基準帯域 ÷ 帯域**。既定 100Mbps だと 100M 以上が全部 1 → **基準帯域を変更** |
| 保守 | **コストを最大**にして迂回 |
| ルータ ID | **ループバック**に付ける |
| DR/BDR | プライオリティ（既定 1、**0 は選ばれない**）→ ルータ ID。**プリエンプトしない** |
| ネイバーにならない | **Hello / Dead 間隔**、**エリア ID**、認証が不一致 |
| セキュリティ | **パッシブインタフェース**、**ネイバー認証** |
| エリア 0 | 全エリアはエリア 0 につなぐ。無理なら**仮想リンク** |
| LSA | **Type 1・2 はエリア内**、**Type 3 は ABR**、**Type 5 は ASBR** |
| スタブ | **Type 5 が入らない**。**NSSA** は ASBR を置ける（Type 7） |
| 経路集約 | **ABR と ASBR だけ** |
| IPsec の上 | **GRE over IPsec** |

### 答えの型

| 問われ方 | 答えの型 |
| --- | --- |
| 基準帯域を変更する理由 | 「100Mbps 以上の**コストがすべて 1** になり、**帯域の違いが反映されない**から」 |
| 保守前にコストを最大にする理由 | 「**別の経路に迂回**させ、**通信を止めずに**作業するため」 |
| パッシブにする理由 | 「端末側に **Hello を送らず**、**不正なルータとの隣接**を防ぐため」 |
| ネイバー認証の理由 | 「**不正なルータ**が**誤った経路を広告**するのを防ぐため」 |
| スタブエリアの利点 | 「**Type 5 が入らず**、**LSDB とルーティングテーブルが小さく**なる」 |
| ABR で集約する利点 | 「テーブルが小さくなり、**細かい変化がほかのエリアに伝わらない**」 |
