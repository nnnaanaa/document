# WIFI.md
## 無線LAN 直前シート

元のシート: [無線LAN 暗記シート](../lan/wifi-cheatsheet.md)

### 要点

| 論点 | 覚えること |
| --- | --- |
| 規格 | **11n は 2.4/5GHz**、**11ac は 5GHz のみ**、**11ax は OFDMA** |
| 2.4GHz 帯 | **電子レンジ・Bluetooth と干渉**。重ならないのは **1・6・11** |
| DFS | **W53・W56** で必要。レーダー検知で**チャネルが変わり途切れる** → 避けるなら **W52** |
| CSMA/CA | 衝突を**検出できない**ので**避ける**。**ACK** で確認 |
| 隠れ端末 | **RTS / CTS** |
| WPA2 / WPA3 | WPA2 は **AES（CCMP）**。WPA3 は **SAE ＋ PMF 必須** |
| 802.1X | 端末 ＝ **サプリカント**、AP ＝ **オーセンティケータ**（RADIUS クライアント） |
| EAP | **EAP-TLS はクライアント証明書**、**PEAP は ID・パスワード** |
| 不十分な対策 | **ステルス SSID**、**MAC アドレスフィルタ** |
| ローミング | 802.1X の再認証が遅い → **PMK キャッシュ**、**802.11r** |
| WLC | 集中管理、**チャネルと出力の自動調整** |

### 答えの型

| 問われ方 | 答えの型 |
| --- | --- |
| CSMA/CA を使う理由 | 「送信中に**ほかの電波を受信できず**、衝突を**検出できない**から」 |
| RTS / CTS で防ぐもの | 「**隠れ端末**どうしの送信が **AP で衝突**するのを防ぐ」 |
| W53・W56 で途切れる理由 | 「**DFS** で**レーダーを検知**すると**チャネルを変更**するから」 |
| ステルス SSID が不十分な理由 | 「**プローブ要求**などから SSID が**盗聴で分かる**から」 |
| WPA3（SAE）の利点 | 「盗聴されても**パスフレーズをオフラインで総当たりされない**」 |
| プライバシセパレータの目的 | 「同じ AP の**端末同士の通信を禁止**する」 |
| エンタープライズ方式の利点 | 「**利用者ごとに認証**でき、特定の利用者だけ止められる」 |
