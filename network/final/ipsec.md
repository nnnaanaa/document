# IPSEC.md
## IPsec 直前シート

元のシート: [IPsec 暗記シート](../wan-vpn/ipsec.md)

### 要点

| 論点 | 覚えること |
| --- | --- |
| 番号 | **ESP ＝ 50番**（暗号化 ＋ 改ざん検知）、**AH ＝ 51番**（改ざん検知のみ）、**IKE ＝ UDP 500** |
| トンネルモード | 元の IP ヘッダごと暗号化し、**新しい IP ヘッダ**を付ける（拠点間 VPN） |
| SA | **ISAKMP SA は双方向で1本**、**IPsec SA は片方向で2本**。**SPI** で識別 |
| IKEv1 | **メインモードは固定 IP 同士**、**アグレッシブモードは片側が動的 IP でも可** |
| NAT トラバーサル | ESP にポート番号がない → **UDP 4500 のヘッダを付ける** |
| MSS の調整 | ヘッダ追加による**フラグメントを防ぐ** |
| 動的ルーティング | IPsec は**マルチキャストを通せない** → **GRE over IPsec** |
| DPD | 相手の障害を検知し、**予備のトンネルへ切り替え** |

### 答えの型

| 問われ方 | 答えの型 |
| --- | --- |
| NAT トラバーサルが必要な理由 | 「ESP には**ポート番号がなく**、NAPT で変換できないから」 |
| アグレッシブモードを使う理由 | 「拠点の IP アドレスが**動的**で、IP アドレスで相手を識別できないから」 |
| 接続を拠点側から始める理由 | 「本社側は拠点の **IP アドレスが分からない**から」 |
| MSS を小さくする理由 | 「ヘッダが付いて MTU を超え、**フラグメントが起きるのを防ぐ**ため」 |
| GRE を組み合わせる理由 | 「IPsec は**マルチキャストを通せない**ので、GRE で包んで OSPF を流すため」 |
| 証明書認証の利点 | 「拠点ごとに**失効させられる**。事前共有鍵の管理が要らない」 |
| ハブ＆スポークの欠点 | 「拠点間通信が本社を通り、**本社に負荷が集中**する」 |
