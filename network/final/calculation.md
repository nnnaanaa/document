### 公式

| 求めるもの | 式 |
| --- | --- |
| 伝送時間 | **データ量（ビット）÷（回線速度 × 回線利用率）** |
| 通信量（SNMP） | **カウンタの差 × 8 ÷ 取得間隔（秒）** |
| 稼働率 | **MTBF ÷（MTBF ＋ MTTR）** |
| 直列 / 並列 | **A × B** / **1 −（1 − A）×（1 − B）** |
| 待ち行列 | ρ ＝ 到着率 × サービス時間。待ち時間 ＝ **ρ ÷（1 − ρ）× サービス時間** |
| 呼量 | **呼数 × 平均保留時間 ÷ 観測時間**（アーラン） |
| VoIP（G.711・20ms） | （160 ＋ **40**）× 8 × **50** ＝ **80kbps**。ヘッダ ＝ RTP 12 ＋ UDP 8 ＋ IP 20 |
| TCP のスループット | **ウィンドウサイズ（ビット）÷ RTT** |
| 伝搬遅延 | 距離 ÷ 約 20 万 km/秒（1,000km で約 5ms） |
| MSS | **1500 − 20 − 20 ＝ 1460**（IPv6 は 1440）。PPPoE の MTU は **1492** |
| フルメッシュ | **n(n − 1) / 2**（ハブ＆スポークは n − 1） |
| 鍵の数 | 共通鍵 **n(n − 1) / 2**、公開鍵 **2n** |
| ホスト数 | **2^(ホスト部) − 2** |

### 覚えておく数

| 数 | 値 |
| --- | --- |
| 2^12 / 2^16 / 2^24 / 2^32 | 4,096（VLAN）/ 65,536（ポート）/ 約1,677万（VNI）/ 約43億（IPv4・32bit カウンタ） |
| 稼働率と年間停止 | 99.9% → 約 8.8 時間、99.99% → 約 53 分 |
| VXLAN | ＋50 バイト |

### 失点しないために

- **× 8**（ビットとバイト）を最初に確認する
- k・M・G は **10^3・10^6・10^9**
- 回線利用率・伝送効率は**回線速度に掛ける**
- 台数・回線数・パケット数は**切り上げ**
- 答えの**単位**を問題文に合わせる
