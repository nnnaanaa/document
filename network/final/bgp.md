# BGP.md
## BGP 直前シート

元のシート: [BGP 暗記シート](../routing/bgp-cheatsheet.md)

### 要点

| 論点 | 覚えること |
| --- | --- |
| プロトコル | **TCP 179**、**パスベクタ型**、**差分更新** |
| メッセージ | **OPEN / UPDATE / NOTIFICATION / KEEPALIVE** |
| NEXT_HOP | **eBGP は書き換え、iBGP は書き換えない** → **next-hop-self** |
| iBGP の制約 | iBGP で学んだ経路は**ほかの iBGP ピアに広告しない** → **フルメッシュかルートリフレクタ** |
| プライベート AS | **64,512〜65,534** |
| 優先の向き | **LOCAL_PREF 大**、**AS_PATH 短**、**MED 小**（大きいほうが優先は LOCAL_PREF だけ） |
| 出ていく通信 | **LOCAL_PREF** |
| 入ってくる通信 | **AS_PATH プリペンド**、**MED**、**細かいプレフィックス** |
| 同じ AS 番号の拠点 | **as-override / allowas-in** |
| 障害の検知 | **KEEPALIVE がホールドタイム内に届かない** → 経路が消える |
| ほかとの関係 | **静的経路は BGP より優先**。**VRRP は BGP 確立後にマスターに** |
| セキュリティ | **MD5 認証**。**RTBH は宛先ごと**、**Flowspec は条件で**捨てる |

### 答えの型

| 問われ方 | 答えの型 |
| --- | --- |
| next-hop-self の理由 | 「iBGP では **NEXT_HOP が書き換わらず**、**外部のネクストホップに到達できない**から」 |
| フルメッシュか RR の理由 | 「iBGP の経路は**ほかの iBGP ピアに広告しない**ので、**全ルータに届ける**ため」 |
| 出ていく回線の制御 | 「優先したい経路の **LOCAL_PREF を大きく**する」 |
| 入ってくる回線の制御 | 「予備側に **AS_PATH プリペンド**をして長く見せる」 |
| as-override が必要な理由 | 「**AS_PATH に自分の AS 番号**がある経路を**ループと判断して受け取らない**から」 |
| MD5 認証の理由 | 「**なりすましたルータ**とのピアリングや**不正なパケットの注入**を防ぐ」 |
