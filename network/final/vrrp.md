# VRRP.md
## VRRP 直前シート

元のシート: [VRRP 暗記シート](../redundancy/vrrp.md)

### 要点

| 論点 | 覚えること |
| --- | --- |
| PC の設定 | **デフォルトゲートウェイ ＝ 仮想 IP** |
| マスタの選出 | **優先度が最大**。同じなら実 IP が大きいほう |
| アドバタイズメント | **マスタが 224.0.0.18 宛て**に送る。届かなくなるとバックアップが昇格 |
| 仮想ルータの数 | VRID は **1〜255** |
| 切替え | **GARP で L2SW の MAC テーブルを更新**。PC の ARP は変わらない |
| 上位側の障害 | **切り替わらない** → **トラッキングで優先度を下げる** |
| プリエンプト | 有効なら**自動で切り戻る** |
| 負荷分散 | **グループを2つ** |
| STP との組合せ | **ルートブリッジとマスタを同じ機器に** |

### 答えの型

| 問われ方 | 答えの型 |
| --- | --- |
| VRRP の利点 | 「故障しても、PC の**デフォルトゲートウェイの設定を変えずに**通信を続けられる」 |
| マスタ故障の検知 | 「**アドバタイズメントを一定時間受信しない**ことで検知」 |
| GARP を送る理由 | 「L2SW の **MAC アドレステーブルを更新**させるため」 |
| ARP を更新しなくてよい理由 | 「**仮想 IP と仮想 MAC が変わらない**から」 |
| WAN 側障害で切り替わらない理由 | 「**LAN 側ではアドバタイズメントが届き続ける**から」 |
| その対策 | 「WAN 側を監視し、障害時に**優先度をバックアップより下げる**」 |
| プリエンプト無効の理由 | 「自動切戻しの**通信断を避け**、時刻を管理者が決めるため」 |
| 2台ともマスタになる原因 | 「**アドバタイズメントが届かなくなった**から」 |
