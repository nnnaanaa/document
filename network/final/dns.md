# DNS.md
## DNS 直前シート

元のシート: [DNS 暗記シート](../protocol/dns.md)

### 要点

| 論点 | 覚えること |
| --- | --- |
| ポート | **UDP 53**、応答が大きいとき・ゾーン転送は **TCP 53** |
| 問合せ | PC → キャッシュ DNS は**再帰**、キャッシュ DNS → 権威は**反復** |
| フォワーダ | 自分で調べず**別のキャッシュ DNS に転送** |
| MX | **プリファレンス値が小さいほう**が優先 |
| CNAME | 相手が IP を変えても**自分の設定を変えなくてよい** |
| TXT / PTR / SRV | **SPF・DKIM・DMARC** / **逆引き** / サービスのホスト名とポート |
| TTL | 移行の**前に短く**しておく |
| ゾーン転送 | **SOA のシリアル番号が増えたら**転送。**NOTIFY** ですぐ知らせる |
| ラウンドロビン | **故障を検知しない** |
| 構成 | **権威とキャッシュを分ける**、**オープンリゾルバにしない** |
| 大きい応答 | 512Byte 超 → **TC ビット** → **TCP 53** で再問合せ（EDNS0 で UDP のまま大きくも） |
| ポイズニング対策 | **送信元ポートと ID をランダムに**、**DNSSEC**（署名。暗号化はしない） |
| DoT / DoH | **TCP 853 / 443** で暗号化 |

### 答えの型

| 問われ方 | 答えの型 |
| --- | --- |
| 移行前に TTL を短くする理由 | 「**古い IP アドレスのキャッシュが残る時間を短くする**ため」 |
| ラウンドロビンの問題点 | 「**故障を検知できず**、故障したサーバの IP も応答する」 |
| 権威とキャッシュを分ける理由 | 「外部からの**再帰問合せを受けず**、**リフレクタ攻撃の踏み台**やポイズニングを防ぐ」 |
| ゾーン転送を制限する理由 | 「**内部のホスト名や IP を第三者に読み出されない**ため」 |
| セカンダリに反映されない原因 | 「SOA の**シリアル番号を増やしていない**」 |
| 大きい応答だけ届かない原因 | 「512Byte を超え、**TCP 53 の再問合せが FW で遮断**されている」 |
