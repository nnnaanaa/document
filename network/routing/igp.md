# IGP.md
## RIP と OSPF（IGP）

***

## RIP (Routing Information Protocol)

| 用語 | 内容 |
| --- | --- |
| **コンバージェンス** | ルーティング情報の変化に対する収束速度が遅い（**30秒ごとの更新**であるためラグがある） |
| **ルートポイズニング** | 到達不能になったルートがあった場合、情報を流さないのではなく、そのルートのホップ数を**最大値（通常16ホップ）**として通知する。これにより、そのルートが無効であることを示す |
| **分割ホライズン**（スプリットホライズン） | ルーティングループを防ぐために、送信元から学習した情報をそのインターフェースを通じて返さない |
| **ポイズンリバース** | ルーティングループを防ぐために、情報が無効になった際、逆方向に「無効」情報を送信。**スプリットホライズンより優先**される。冗長構成がある場合に有効 |

**RIPバージョン**: RIP v1（クラスフル）、RIP v2（**クラスレス**）、RIPng（IPv6用）

## OSPF (Open Shortest Path First)

### エリアの概念

ルーターの台数が増えてトポロジーが大きくなりすぎると情報が多くなって計算量が増えるため、適度にエリアに分割する。エリア内のルータは**エリア内の情報のみ**を持つ。エリア外の情報は**境界ルーター**しかもたない。

| 用語 | 内容 |
| --- | --- |
| **指名ルータ**（Designated Router / DR） | OSPFエリア内で複数の全ルーターが互いにリンクステート情報を交換するのは非効率。そのため、指名ルーター（DR）が選出され、他のルーターからリンクステート情報を収集し、ネットワーク全体にそれを伝播させる |
| **副指名ルータ**（Backup Designated Router / BDR） | DRが障害発生時にすぐに代替できる、副指名ルーター（BDR）も選出される |
| **境界ルータ**（Area Border Router / ABR） | OSPFの異なるエリア間のルーティングを仲介する。AS（自律システム）の境界で動くルーターを**AS境界ルーター（ASBR）**という |

構成例: エリア1・エリア2がそれぞれABRを介して**バックボーンエリア（エリア0）**に接続される。

### LSAの主なType

| LSA Type | 名称 | 説明 |
| --- | --- | --- |
| 1 | ルーターLSA (Router LSA) | **全OSPFルータ**が生成。ルーターが所属するエリア内のリンクステート情報を提供。直接接続されているネットワークや他のルーターとの接続（自身のルーターID、インターフェースのIPアドレスやコストなど）を示す。**自分のエリア内**にフラッディング |
| 2 | ネットワークLSA (Network LSA) | **指名ルーター(DR)が生成**し、ブロードキャストネットワークセグメント（L2ネットワーク）に接続されているすべてのルーターの情報を提供。**自分のエリア内**にフラッディング |
| 3 | ネットワークサマリーLSA (Network Summary LSA) | **境界ルーター(ABR)が生成**し、他のエリアに送信する自および他のエリアのネットワークプレフィックス情報を提供。タイプ1と2は、ABRによってタイプ3に変換され、エリア0/バックボーンエリアを通じてABR間でやり取りする |
| 4 | ASBRサマリーLSA (ASBR Summary LSA) | **境界ルーター(ABR)が生成**、AS境界ルーター(ASBR)の位置をエリア内のルーターに知らせるための情報を提供。Type5とセットで利用 |
| 5 | AS外部LSA (AS External LSA) | **AS境界ルーター(ASBR)が生成**し、OSPFドメイン外のネットワークプレフィックス（外部ルート）の情報を提供 |
