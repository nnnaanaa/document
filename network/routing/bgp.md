# BGP.md
## BGP (Border Gateway Protocol)

***

## BGPメッセージ

| メッセージタイプ | タイプコード | 説明 |
| --- | --- | --- |
| OPEN | 1 | BGPセッションの確立を要求するメッセージ。BGPバージョン、AS番号、ホールドタイマー、BGP識別子などを含む |
| **UPDATE** | 2 | ルートの広告や更新を行うメッセージ。新しいルートの追加、既存ルートの削除、パスアトリビュートの変更を含む |
| NOTIFICATION | 3 | エラーが発生した場合に送信されるメッセージ。エラーの種類や詳細な説明を含む |
| KEEPALIVE | 4 | セッションの生存確認を行うメッセージ。セッションの状態が正常であることを確認するために定期的に送信される |

## パスアトリビュート

UPDATEメッセージに含まれる経路情報にパスアトリビュートを付加することによって経路制御を行う。「アトリビュート（attribute）」は、一般的に「属性」や「特性」を意味する。

| アトリビュート名 | タイプコード | 説明 |
| --- | --- | --- |
| ORIGIN | 1 | ルートの起源。IGP、EGP、インターネットによるものを示す |
| **AS_PATH** | 2 | ルートが通過したASのリスト。**ループ検出**に使用。**ASプリペンド**に使用 |
| NEXT_HOP | 3 | 次に到達すべきルータのIPアドレス |
| **MED** (MULTI_EXIT_DISC) | 4 | 他のASからのエクジットポイントの優先度。**低いほど優先**される |
| **LOCAL_PREF** | 5 | 同一AS内でのルートの優先度。**高いほど優先**される |
| ATOMIC_AGGREGATE | 6 | ルートがアグリゲートされたことを示す |
| AGGREGATE_PATH | 7 | アグリゲートされたルートのパス |
| **COMMUNITY** | 8 | コミュニティ属性。ルートのグループ化やフィルタリングに使用 |

## AS_PATHプリペンド

AS_PATHプリペンドは、BGPのパスアトリビュートの操作方法の一つで、AS_PATHアトリビュートに特定のAS番号を**意図的に**追加することで、ルートの優先度を調整する手法。具体的には**AS_PATHアトリビュートに自AS番号を複数回追加**し、これにより、ルートの長さを意図的に長くし、他のASがそのルートを選ばないようにする。

例）`AS_PATH: AS65001 AS65001 AS65001 AS65002 AS65003`

これにより、AS_PATHが長くなり、他のASがこのルートを選択する際に不利になることを目的としている。

## BGPのループ検出とその回避

**ループ検出**: AS_PATHを基にループを検知。AS_PATH内に自AS番号が含まれる場合、ループと判断して経路を破棄する。実際にはループ構成でなくともループと検知される場合、`as-override` や `allowas-in` で回避できる。

例）AS65500 → AS64500（AS_PATH: 65500）→ AS65500（AS_PATH: 64500 65500）で経路が破棄される。

| 回避方法 | 内容 |
| --- | --- |
| **as-override** | 広報する経路のAS_PATH内にBGPネイバーのAS番号が含まれる場合、**自AS番号に書き換えて広報**（`neighbor x.x.x.x as-override`） |
| **allow-as-in** | 受信する経路のAS_PATH内に自AS番号が含まれる場合、それをループと判断せずに**受け入れる**（`neighbor y.y.y.y allowas-in`） |

## AS番号の分類

BGPを利用する時は、IPアドレス以外にAS（Autonomous System）番号が必須。**ASN**（AS Number）として表記されることも。

| 分類 | 範囲 |
| --- | --- |
| 2 Bytes AS番号（16ビット） | 1〜65,535の範囲 |
| ├ グローバルAS番号 | 1〜64,511の範囲 |
| └ **プライベートAS番号** | **64,512〜65,535の範囲** |
| 4 Bytes AS番号（32ビット） | 65,536〜4,294,967,295の範囲 |
| ├ グローバルAS番号 | 65,536〜4,199,999,999 |
| └ **プライベートAS番号** | **4,200,000,000〜4,294,967,295** |

インターネットで使われないIP＝プライベートIP、インターネットで使われないAS番号＝プライベートAS番号。プライベートAS番号はインターネット上では使えず、企業内やVPNなど、閉じたネットワークで使用される。

※ 実際にAS番号65500について問われ、プライベートAS番号と回答させるような問題があった。

## BGPルートリフレクタ

iBGPネットワークにおいて、iBGPピアから受信した経路を他のiBGPピアに広報（反射）する構成。iBGPでは他のiBGPピアから学習した経路を他のiBGPピアには広報しないため、原則はフルメッシュ型のネットワークが必要となり、スケーラビリティに乏しい。

**ルートリフレクタ構成を採用すればフルメッシュ構成が不要**となる。複数のルートリフレクタが存在する場合、ループ防止のために「**クラスターID**」を設定する。

→ ルートリフレクタによりiBGPネットワークをシンプルに構成可能となる。
